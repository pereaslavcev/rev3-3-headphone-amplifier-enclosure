# Корпус усилителя Rev.3.3 Curved

Параметрическая компоновочная модель корпуса лампового усилителя для наушников Rev.3.3. Проект включает исходную Blender-сцену, экспорт GLB, четыре рендера и статическую страницу предпросмотра.

![Общий вид корпуса](renders/01_Корпус_общий_вид.png)

## Состав

- `src/model.py` — параметрическое моделирование шасси, плат, ламп, трансформаторов, радиаторов, разъёмов и защитной решётки; сохранение Blend и экспорт GLB.
- `src/render.py` — основной, внутренний, задний рендеры и рендер с защитной решёткой.
- `model/Корпус_Rev3_3.blend` — редактируемая самодостаточная сцена Blender.
- `model/Корпус_Rev3_3.glb` — экспортированная модель в метрах, без студийного пола и источников света.
- `renders/` — четыре PNG-рендера.
- `index.html` — галерея предпросмотра и ссылки на файлы.

## Основные размеры

| Параметр | Значение |
|---|---:|
| Номинальное шасси | 450 × 360 × 78 мм |
| Сборка с накладками, органами управления и решёткой | 474 × 402 × 211 мм |
| Audio PCB | 271 × 203 × 2 мм |
| PSU PCB | 130 × 155 × 2 мм |
| Крепёж плат | M3 |

В сборке представлены четыре лампы, T1, два выходных трансформатора T2, дроссель Hammond 193L, четыре радиатора Fischer SK 409 для внешних TL783C, Neutrik RCA и 6,35 мм jack, ALPS RK27 и съёмная защитная решётка.

## Воспроизведение

Рекомендуется Blender **5.2.1 LTS**. Внешние Python-зависимости для моделирования и рендеринга не требуются.

```bash
blender --background --python src/model.py
blender --background --python src/render.py main
blender --background --python src/render.py interior
blender --background --python src/render.py guard
blender --background --python src/render.py rear
```

Для локального предпросмотра страницы:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000`.

## Компоновочные допущения

- T1 условно принят Ø140 × 80 мм.
- Каждый T2 условно принят 92 × 82 × 88 мм.
- Лампы и разъёмы представлены внешними оболочками, а не точными CAD производителей.
- Компоненты на платах показаны упрощённо.

Перед изготовлением необходимо подставить фактические трансформаторы и проверить крепления, электрические зазоры, вентиляцию и тепловой режим. **Это компоновочная 3D-концепция, не производственный чертёж.**
